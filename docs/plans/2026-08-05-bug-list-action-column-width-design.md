# Bug 列表操作列宽度设计

## 目标

保证全局 Bug 列表的固定操作列完整显示关注、工作流动作、更多和删除按钮。

## 范围

- 仅调整 `BugsView.vue` 的操作列宽度参数。
- 不改变操作的可见性、顺序、权限、工作流分组或响应式布局。
- 不修改其他工作项列表和共享列宽计算函数。

## 方案

保留 `workflowActionColumnWidth()` 对动态工作流动作的计算。在 Bug 页面将其选项改为 `minWidth: 240`、`extraWidth: 160`：其中附加空间覆盖关注按钮的 `92px` 最小宽度、删除按钮及两段 `8px` 间距；工作流主按钮和“更多”仍由共享函数按当前行动态累加。

## 验证

新增页面源契约测试，断言 Bug 页面向列宽计算器传入 `minWidth: 240` 与 `extraWidth: 160`。运行该测试、前端全量测试、构建和差异检查。
