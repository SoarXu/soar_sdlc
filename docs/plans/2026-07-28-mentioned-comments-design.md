# 提到我的评论列表设计

## 目标

将工作台“提到我的”从按工作项聚合的列表调整为按评论展示的列表，让用户直接看到每次 `@` 提及所在的评论内容。

## 数据流

后端继续以当前用户、项目可见范围和活跃迭代作为筛选边界。对每条 `mentioned_user_ids` 包含当前用户的工作项评论，返回对应工作项的现有展示字段，并附加评论 ID、正文、评论人和评论时间。相同工作项上的多条评论必须分别返回，并按评论时间倒序排列。

## 界面

“提到我的”页签保留类型、工作项标题、项目、迭代、处理人和状态，改用专用列展示“评论内容”“评论人”“评论时间”。工作项标题仍可跳转至详情；其他工作台页签不改变。

## 边界与验证

没有评论正文时显示空占位，评论正文使用现有表格溢出提示。测试覆盖同一工作项多次提及、评论元数据透传、排序，以及前端列定义和视图模型描述。
