# 手动与自动工作项评审 Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 让需求、任务和 Bug 支持手动或 DevOps 自动提交评审，并在待评审状态通过统一弹窗查看 Git Diff、通过或驳回。

**Architecture:** 以 `WorkItemReviewRound` 作为三类工作项的唯一评审上下文，允许其没有关联提交。后端统一处理提交评审、自动提交补充 Diff 和评审决定；前端以可复用弹窗承载评审。默认工作流模板和已有默认模板迁移为人工、自动两种入口共用的评审子图。

**Tech Stack:** FastAPI、SQLAlchemy、Alembic、Vue 3、Element Plus、Node 测试脚本、pytest。
