# 角色 ID 关联改造 Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 以业务角色 ID 替换所有业务角色文本关联，并将系统管理员改为用户字段。

**Architecture:** 角色名称仅作展示，所有业务引用保存角色 ID。工作流内置身份继续使用受控枚举；业务角色多选以关联表保存，运行时通过角色 ID 查询项目成员。

**Tech Stack:** FastAPI、SQLAlchemy、Alembic、MySQL、Vue 3、Element Plus、pytest、Vite。
