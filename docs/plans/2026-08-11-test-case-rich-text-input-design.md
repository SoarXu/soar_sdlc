# 测试用例富文本输入设计

## 目标

测试用例的前置条件、步骤、步骤预期和总预期结果统一支持富文本录入与截图粘贴，并在详情页正确展示保存后的内容。

## 方案选择

复用现有 `frontend/src/components/RichTextPasteEditor.vue`。该组件基于 `contenteditable` 提供格式化内容和图片粘贴能力，并通过 `sanitizeHtml` 移除脚本、事件属性和 JavaScript URL。相较于引入新的带工具栏编辑器，该方案不增加依赖，且与 Bug 复现步骤保持一致。

## 数据与界面

前置条件和总预期结果继续作为字符串保存；`steps_json` 中每一项的 `step` 与 `expected` 也继续作为字符串保存。后端 Pydantic 模型和数据库字段无需迁移。

项目详情的测试用例新增/编辑弹窗及测试用例详情页的编辑表单，均将四类说明输入替换为 `RichTextPasteEditor`。测试用例详情的前置条件、总预期结果、步骤列和预期列使用 `v-html` 展示已由编辑器清洗过的内容；空值仍显示现有占位内容。

## 验证

新增前端源级契约测试，覆盖两个录入入口的编辑器绑定及详情页的 HTML 渲染。先观察测试因缺少绑定和渲染而失败，再实施最小变更，最后运行定向测试、完整前端测试与构建。
