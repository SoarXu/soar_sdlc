# 测试用例 Excel 批量导入

## 操作入口

- 项目详情 → 测试 → 测试用例 → 导入用例：目标项目已固定。
- 测试管理 → 导入用例：先选择目标项目。
- 项目详情 → 需求 → 单条需求的“导入用例”：自动选择默认关联需求。

## 填写与关联

在导入弹窗下载当前项目的模板，一行填写一条用例，用例标题必填。

“关联需求”可从 Excel 下拉选择 `标题【需求#ID】`，系统自动按 ID 关联，不需要手动查询 ID。模板内的需求清单包含标题、迭代和状态，可用于区分同名需求。也可以直接输入标题：当前项目内标题唯一时自动匹配；重名或找不到时，预检页面按所填名称分组，一次选择应用到该组全部用例，也可明确指定暂不关联。

留空“关联需求”的用例使用弹窗中的默认需求；没有默认需求则不关联。Excel 中已填写的关联需求优先于默认需求。

用例类型默认为功能测试，适用范围默认为功能测试环节。适用范围支持中文分号分隔多个范围。测试人填写系统账号，留空使用项目配置的默认测试人。前置条件、用例步骤和预期结果支持单元格内换行，按文字导入；导入后可使用平台富文本编辑器补充图片。

## 预检与确认

上传后点击预检。预检展示错误的 Excel 行号、需求关联分组和前 100 条用例预览。可以集中修正需求关联；其他单元格错误需在 Excel 修改后重新上传。修改项目、默认需求、分组关联、文件或重复策略后，必须重新预检才能确认。

重复按“同项目、同需求、相同标题”判断，包含文件内重复。默认跳过重复，也可选择仍然新增；不会更新或覆盖已有用例。

仅支持 `.xlsx`，每次最多 1000 条、10MB，不接受公式及嵌入图片。预检不会新增数据；确认时再次校验权限和需求关联，整批保存，发生错误则全部回滚。成功后显示新增数和跳过数并刷新列表。
