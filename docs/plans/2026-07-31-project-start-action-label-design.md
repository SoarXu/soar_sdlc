# 项目启动动作命名设计

## 目标

将项目工作流中 `start` 动作的显示名称从“开始”统一为“启动”。

## 范围

- 仅处理 `object_type = project` 且 `action_key = start` 的工作流流转。
- 更新系统默认定义及项目已经引用的工作流副本。
- 不修改流转键、状态、实际开始日期逻辑或迭代、需求、任务、缺陷的工作流。

## 方案

新增 Alembic 数据迁移，按项目对象和 `start` 键更新 `workflow_transitions.action_name`，并同步该流转的表单标题和提交按钮文案。前端继续直接显示后端返回的 `action_name`，无需加入对象特例。

## 验证

新增后端迁移测试，构造项目和非项目 `start` 流转，确认仅项目流转及其表单文案更新；保留前端工作流操作按钮契约测试，确保按钮显示服务端动作名称。
