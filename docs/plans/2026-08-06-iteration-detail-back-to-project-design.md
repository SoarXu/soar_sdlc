# 迭代详情返回项目设计

## 目标

从项目详情的迭代列表进入迭代详情时，在页面左上角显示“回到项目”按钮，点击后返回来源项目的迭代 Tab。

## 设计

- 项目详情现有跳转继续携带 `from=project`、`projectId` 和 `tab=iterations`。
- 迭代详情仅在 `from=project` 且 `projectId` 是有效正整数时显示“回到项目”。
- 点击后使用命名路由进入 `project-detail`，参数为来源 `projectId`，查询参数固定为 `tab=iterations`。
- 从全局迭代列表或其他入口进入时不显示该按钮，现有“返回迭代列表”保持不变。

## 验证

- 源码契约测试覆盖按钮显示条件和返回路由。
- 运行完整前端测试和生产构建。
