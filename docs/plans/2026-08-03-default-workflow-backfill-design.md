# 默认工作流方案空白流程回填设计

## 背景

`默认工作流规则` 是历史创建的默认方案。该方案缺少需求、任务和 Bug 的工作流定义；前端在切换对象类型时会创建空定义，导致画布显示为空。

系统级的需求、任务和 Bug 标准工作流仍然完整存在。

## 目标

在读取默认工作流方案时，自动恢复该方案中缺失或完全空白的需求、任务和 Bug 工作流。

## 回填规则

- 仅处理名称为系统默认方案的 `AssigneeRuleConfig`。
- 仅处理 `requirement`、`task`、`bug` 三种对象类型。
- 定义缺失时创建定义并复制系统标准模板。
- 定义同时没有状态和流转时复制系统标准模板。
- 已有任何状态或流转的定义视为用户配置，绝不覆盖。
- 项目工作流及其他工作流方案不受影响。

## 实现与验证

复用系统模板和现有图复制逻辑，补齐定义、初始状态、状态节点与流转规则。增加服务层测试，覆盖缺失、空白和非空定义三种情形，并确认页面重新加载后可读取恢复后的图。
