# 项目详情列表状态保持设计

## 目标

项目详情页的需求、任务、测试用例、测试单和 Bug 列表分别保存筛选条件、当前页和每页条数。进入记录详情后返回、项目内切换标签、浏览器前进/后退、刷新或离开项目后重新进入时，恢复各自最近状态。

## 方案

将状态编码到项目详情路由查询参数。每个列表使用独立命名空间，例如 `requirements_keyword`、`requirements_iteration_id`、`requirements_page`、`requirements_page_size`，任务、测试用例、测试单和 Bug 使用对应前缀。`tab` 继续表示当前标签，`test_tab` 表示测试子标签（用例/测试单）。

`ProjectDetailView.vue` 挂载时从查询参数初始化五组筛选和分页对象；筛选、分页或标签变化时使用 `router.replace` 同步查询参数。进入需求、任务、测试用例或 Bug 详情时传递当前完整项目查询参数，详情页从 `from=project` 返回项目详情时原样保留查询参数。非法分页值回退到各列表现有默认值，且不把表格选中行、弹窗内容等临时状态写入 URL。

## 测试

- 纯函数测试覆盖项目列表状态分组序列化/解析、默认值、非法分页和测试子标签。
- 源码契约测试确认项目详情从路由初始化、筛选/分页同步、详情链接传递查询参数。
- 详情返回测试确认需求、任务、测试用例和 Bug 均保留项目查询参数。
- 运行完整前端测试和 Vite 生产构建。
