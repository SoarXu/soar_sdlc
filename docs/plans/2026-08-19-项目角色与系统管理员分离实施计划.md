# 项目角色与系统管理员分离 Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 将后台用户全局角色收敛为系统管理员资格，保留后台业务角色字典维护，并使业务角色仅由项目成员配置生效。

**Architecture:** 用户 API 使用 `is_system_admin` 维护唯一全局角色。角色 API 继续维护业务角色字典，项目成员下拉框从该字典选择角色；项目权限和工作流角色解析仅合并系统管理员身份与项目成员角色，迁移清理遗留全局业务角色。

**Tech Stack:** FastAPI、SQLAlchemy、Alembic、Vue 3、Element Plus、pytest、Node `assert`、Vite。
