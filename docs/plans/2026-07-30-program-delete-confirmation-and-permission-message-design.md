# 项目集删除确认与权限提示中文化设计

## 目标

将项目集删除确认改为居中模态弹窗，并将项目集治理权限拒绝提示统一为“无权限”。

## 范围

- 删除按钮通过 Element Plus `ElMessageBox.confirm` 展示居中确认框。
- 确认框保留删除项目集会一并删除子项目集和下属项目的风险说明。
- 取消时不调用删除接口；确认后复用既有删除逻辑。
- 后端全部项目集治理权限拒绝路径继续返回 HTTP 403，但错误详情改为“无权限”。
- 前端沿用现有错误格式化逻辑展示服务端文案。

## 验证

- 前端静态契约测试覆盖模态确认调用和删除执行顺序。
- 后端测试覆盖三个治理权限拒绝路径的中文错误详情。
