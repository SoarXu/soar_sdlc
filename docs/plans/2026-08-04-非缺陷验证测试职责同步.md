# 非缺陷验证测试职责同步实施计划

**目标：** 让关联任务关闭门禁测试使用实际被路由的验证人，确保测试覆盖关闭门禁而非被权限校验提前中断。

**范围：** `backend/tests/test_linked_task_api.py` 的测试数据和身份切换。

## 步骤

1. 阅读 `backend/app/services/default_workflow_template_service.py` 中 `confirm_bug_type` 的验证人路由，以及相关 PRD 的非缺陷验证职责规则。
2. 保留当前复现：开发处理人将 Bug 判定为“设计如此”后，使用其令牌执行 `verification_passed` 得到 `403`。
3. 在测试中创建并配置报告人、测试人或项目负责人中的一个有效验证人；在断言处理人已转移后，改用该验证人令牌执行验证通过。
4. 验收开发处理人仍不可越权验证，指定验证人可以进入后续“已验证/关闭”流程；关联任务未完成时的关闭门禁断言继续有效。
5. 执行 `python -m pytest -q tests/test_linked_task_api.py` 和全量后端测试。
