# 项目启动按钮颜色统一设计

## 背景

项目集页面的“启动”操作使用绿色，但项目行通过运行时工作流渲染，项目 `start` 流转未配置 `button_type`，接口默认返回 `primary`，显示为蓝色。

## 决策

在项目默认工作流的 `start` 流转中显式配置 `button_type: "success"`；新增 Alembic 迁移，为数据库内全部项目 `start` 流转补写相同配置。保留其他 `ui_config` 字段，且不改动非项目或非 `start` 流转。

## 验证

迁移单元测试验证旧配置被保留并补入绿色类型，默认模板测试验证新项目的配置；执行目标测试、前端构建和差异检查。
