# 工作台评审统一入口 Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 移除工作台重复评审区块，并让代码评审决定按钮由工作流运行时数据驱动。

**Architecture:** 工作台继续以进行中迭代工作项列表作为唯一入口。`WorkItemReviewDialog` 并行读取评审上下文和运行时流转，筛选两条评审决定流转后渲染按钮，服务端保持既有的评审决定接口。

**Tech Stack:** Vue 3 Composition API、Element Plus、Axios、Node `assert` 测试、Vite。
