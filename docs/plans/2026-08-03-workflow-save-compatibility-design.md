# 工作流保存兼容性修复设计

## 根因

- 项目流程的历史迁移标记 `ui_config.migration_origin` 被前端原样提交，后端编辑配置白名单拒绝该字段。
- 缺陷默认流程的 `form_config.allow_unassigned` 是系统模板已有字段，但后端表单配置白名单遗漏该字段。

## 修复

- 前端提交流程图时删除 `migration_origin`，该字段仅用于历史追溯，不参与运行时配置。
- 后端将 `allow_unassigned` 作为合法表单配置字段保留。
- 其余未知 UI 和表单字段继续拒绝。

## 验证

使用项目与缺陷流程的前端序列化载荷执行保存回归测试，断言接口成功且未知字段仍被拒绝。
