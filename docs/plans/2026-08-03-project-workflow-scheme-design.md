# 项目工作流方案化设计

## 目标

在工作流方案的可视化编辑器中增加“项目”类型。项目创建时若选择工作流方案，使用该方案中的项目工作流定义和初始状态；未选择方案则继续使用系统默认项目工作流。

## 方案边界

工作流方案创建、复制和模板克隆均包含需求、任务、Bug、项目四类定义。项目集不纳入本次通用工作流编辑器，仍使用独立的项目集状态逻辑。

历史项目不做状态迁移。经确认，在实施验证前删除现有项目及其项目范围业务数据；工作流方案、默认工作流模板、项目集和用户数据保留。

## 数据流

新建项目持有工作流方案时，后端在写入项目记录后解析该方案的项目定义，并将项目的 `workflow_definition_id` 和 `current_state_id` 初始化为该定义的初始状态。工作流方案编辑器从该方案下读取并保存项目定义，运行时沿用既有按项目定义读取流转的机制。

## 验证

后端测试覆盖方案定义的创建/复制、带方案创建项目和未带方案创建项目；前端源码契约覆盖项目出现在对象类型选择器。完成后清理项目数据，运行迁移和回归测试，并验证新项目的运行时流转来自所选方案。
