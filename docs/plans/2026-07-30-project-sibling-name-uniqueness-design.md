# 同级项目名称唯一性设计

## 目标

同一项目集下的同级项目名称不得重复，名称比较去除首尾空格且不区分大小写。

## 规则

- 作用域为 `program_id + parent_id`。
- 同一作用域内活动项目的规范化名称唯一。
- 不同项目集或不同父项目允许同名。
- 未归属项目集的项目不受本次规则限制。
- 创建、重命名、移动项目集或父项目时均校验目标作用域。
- 冲突返回 HTTP 422 和“项目名称已存在”。

## 实现

- 在项目服务层集中规范化名称并查询活动同级项目。
- 创建与更新均在持久化前调用该校验；更新排除自身。
- 不新增数据库唯一索引，避免既有数据冲突和迁移风险。

## 验证

- 覆盖创建、重命名、跨项目集移动、跨父项目移动、大小写和空白变体。
- 覆盖不同项目集、不同父项目和未绑定项目集可同名。
