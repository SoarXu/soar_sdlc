# 后续问题清单

## 使用范围

本文档用于登记 SOAR SDLC 平台后续发现、尚未解决的问题。每一个问题必须先完成复现和影响确认，再建立对应的中文执行计划；未经验证不得标记为已解决。

## 问题状态

- 待确认：已收到现象，尚未稳定复现或确认影响。
- 待计划：已确认问题，等待制定执行计划。
- 待实施：计划已确认，等待集中处理。
- 实施中：正在修复或补充自动化测试。
- 待验证：实现已完成，等待回归与验收。
- 已解决：验证通过，保留问题、计划和验证证据。

## 待实施

### N-001 测试用例的说明字段未支持富文本输入

- 状态：待实施
- 类型：功能与体验问题
- 优先级：P2
- 发现时间：2026-08-11
- 影响范围：项目详情的测试用例新增和编辑弹窗，以及测试用例详情的编辑与展示界面。
- 复现步骤与证据：进入项目详情的“测试”页新增或编辑用例，或进入任一测试用例详情后编辑。前置条件、每条步骤、每条步骤预期和总预期结果均为普通文本输入控件，不能保留格式或粘贴截图。
- 预期结果：上述所有说明字段均使用统一的富文本输入控件，支持格式化内容和截图粘贴；保存后在测试用例详情页按已清洗的 HTML 正确展示。
- 实际结果：仅 Bug 的复现步骤使用 `RichTextPasteEditor`；测试用例的相关字段仍使用 `el-input`，详情页将内容作为纯文本输出。
- 根因分析：测试用例表单和详情页没有复用现有的富文本编辑与渲染模式，尽管后端字段已使用 `Text` 或 JSON 字段，可保存字符串内容。
- 执行计划：`docs/plans/2026-08-11-test-case-rich-text-input.md`
- 验证结果：待实施。

### N-002 需求可落入默认需求池或已关闭迭代

- 状态：待实施
- 类型：功能与数据一致性问题
- 优先级：P1
- 发现时间：2026-08-11
- 影响范围：项目创建、需求创建和编辑、需求导入、迭代工作项关联与移除、任务和 Bug 的迭代继承，以及项目详情的“待规划工作池”展示。
- 复现步骤与证据：创建项目后系统自动生成“需求池”默认迭代；新增需求未选择迭代时会被自动放入该迭代。需求选择器可保留已关闭迭代，项目详情的待规划工作池以默认迭代中的数据为准。
- 预期结果：每个需求必须关联所属项目中进行中或未开始的真实迭代；创建和编辑时不允许为空或选择已关闭迭代。取消默认需求池。既有默认池数据迁移到可用真实迭代，没有可用迭代时自动创建一个未开始迭代。项目详情保留待规划工作池区域，但汇总进行中和未开始迭代中的需求、任务和 Bug。
- 实际结果：默认需求池作为隐藏迭代承接未排期数据，且相关业务入口依赖其作为回退目标。
- 根因分析：需求池被同时用作“未排期数据容器”和“迭代必填约束的技术回退”，导致真实迭代范围、前端选择规则和后端数据规则不一致。
- 执行计划：`docs/plans/2026-08-11-real-iteration-assignment.md`
- 验证结果：待实施。

### N-003 工作台按来源拆分，无法统一查看进行中迭代工作项

- 状态：待验证
- 类型：功能与体验问题
- 优先级：P2
- 发现时间：2026-08-11
- 影响范围：工作台接口、工作台单表展示、工作项筛选和排序、批量指派与工作流操作入口。
- 复现步骤与证据：进入工作台后，需要在“待处理、待分配、我创建、我关注、提及、异常”等入口之间切换；各入口的数据范围不同，不能在同一列表内查看当前用户有权限访问的进行中迭代全部需求、任务和 Bug。
- 预期结果：工作台默认展示当前用户可见、归属进行中迭代的全部需求、任务和 Bug，以一张表按需筛选。已完成或已取消项保留但排序靠后；默认排序为未结束、逾期、高优先级、临近截止日期、最近更新依次优先。
- 实际结果：数据按队列来源拆分，列表默认范围不等同于用户可见的进行中迭代全部工作项。
- 根因分析：工作台 API 和视图模型围绕多个角色队列构建，没有提供权限范围内按迭代聚合的标准工作项集合。
- 执行计划：`docs/plans/2026-08-11-active-iteration-workbench.md`
- 验证结果：后端定向回归 `pytest tests/test_dashboard_workbench_api.py -q` 通过（18 passed）；前端 `npm test` 和 `npm run build` 通过。后端全量 `pytest -q` 结果为 522 passed、93 failed；失败均由现有需求池工作项在流转时要求目标迭代（`TARGET_ITERATION_REQUIRED`）引起，该校验已存在于基线 `HEAD`，属于 N-002 尚未实施的阻塞项，非本条工作台改动引入。
