# 测试用例批量导入实施计划

**目标：** 在项目测试用例、测试管理提供同一导入流程，Excel 需求下拉自动携带 ID，手填标题可预检匹配和分组指定。

**架构：** 新增测试用例导入服务和 template/preview/commit 接口。模板用 openpyxl 生成需求引用工作表与命名范围下拉；预检只读，提交重新校验并在单个事务中新增。Vue 共用弹窗维护上传、整批默认需求、分组覆盖、重复策略及预检结果。

**技术：** FastAPI、SQLAlchemy、openpyxl、Vue 3、Element Plus。

1. 先写接口测试：模板需求下拉、按 ID/标题关联、重名分组处理、跨项目拒绝、默认需求、重复跳过/新增、富文本转义、非法数据不写入、权限和事务回滚。
2. 实现模板和解析：一行一用例，最多 1000 条/10MB；拒绝图片/公式；按目标项目解析需求、测试人和枚举，保留换行。
3. 实现预检/提交：返回逐行问题和需求分组；支持分组指定需求或明确暂不关联；重检权限、项目、需求和重复项；单事务插入。
4. 共用导入弹窗接入项目详情和测试管理；新增需求行的导入用例快捷入口。项目切换清空上下文，文件/关联/策略变化使预检失效。
5. 运行后端接口测试、相关前端回归和构建，检查 diff。未经用户确认不提交、不推送。
