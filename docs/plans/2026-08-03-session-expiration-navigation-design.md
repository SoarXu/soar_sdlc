# 登录失效跳转设计

## 问题

会话失效提示使用同步的 Element Plus 消息调用，未等待提示关闭；随后通过 Vue Router 跳转登录页，会被工作流编辑器等页面的未保存离开保护取消。

## 决策

将提示包装为在 Element Plus `onClose` 时 resolve 的 Promise。提示关闭后，使用浏览器级 `window.location.replace` 跳转到由路由解析出的登录地址，绕过业务路由守卫。登录请求本身仍不触发会话清理或跳转。

## 验证

会话失效单元测试验证先关闭提示、再导航；HTTP 拦截器源码契约验证提示使用关闭回调，并通过浏览器级跳转进入登录页。执行前端全量测试、构建和差异检查。
